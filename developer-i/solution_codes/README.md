# solution_codes — เฉลยโค้ดฝึกของคอร์สนี้

โฟลเดอร์นี้คือเฉลยของไฟล์ใน `practise_codes/` ชื่อไฟล์ตรงกันตัวต่อตัว
เช่น `practise_codes/s03_box_joystick.py` เฉลยอยู่ที่ `solution_codes/s03_box_joystick.py`

เฉลยมีไว้ให้เทียบ ไม่ได้มีไว้ให้ลอก — คะแนนของคอร์สนี้อยู่ที่ใบงานและการอธิบาย
ไม่ใช่ที่โค้ดตรงกับเฉลย ดังนั้นการ copy เฉลยส่งไม่ได้ช่วยอะไรเลย

## วิธีใช้เฉลยให้ได้ประโยชน์จริง

1. ลงมือทำส่วนที่เว้นไว้ด้วยตัวเองก่อน อย่างน้อย 15 นาที — ติดตรงไหนให้อ่านคำใบ้
   ในไฟล์ฝึกกับในสไลด์ของคาบนั้นก่อน
2. ถ้ายังติด เปิดเฉลย "อ่านให้เข้าใจ" แล้วปิด — กลับไปพิมพ์ด้วยมือตัวเอง
   ตามความเข้าใจ ห้าม copy-paste (การพิมพ์เองคือช่วงที่สมองจำ pattern ได้จริง)
3. รันบนบอร์ดให้เห็นผลจริง แล้วลองแก้ตัวเลข/เงื่อนไขดูว่าพฤติกรรมเปลี่ยนยังไง
4. เขียนใบงานของคาบนั้นด้วยคำพูดตัวเอง — ตรงนี้แหละคือคะแนน

ทำครบสี่ข้อนี้ เฉลยจะเป็นครูอีกคน ไม่ใช่ทางลัด
